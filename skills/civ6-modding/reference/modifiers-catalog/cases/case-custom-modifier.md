# 自定义 DynamicModifier 案例

> 标准 ModifierType 不支持的效果才需要自定义。**必须先注册 Types(KIND_MODIFIER) + DynamicModifiers**。

---

## 注册模板

```sql
-- 1. 注册 Type
INSERT INTO Types (Type, Kind) VALUES
('MODIFIER_SIQI_<编号>_<描述>', 'KIND_MODIFIER');

-- 2. 注册 DynamicModifiers（ModifierType = EffectType + CollectionType 的组合）
INSERT INTO DynamicModifiers (ModifierType, CollectionType, EffectType) VALUES
('MODIFIER_SIQI_<编号>_<描述>', 'COLLECTION_OWNER', 'EFFECT_XXX');

-- 3. 之后才能在 Modifiers 表中使用
INSERT INTO Modifiers(ModifierId, ModifierType) VALUES
('MODIFIER_SIQI_<编号>_<描述>_INSTANCE', 'MODIFIER_SIQI_<编号>_<描述>');
```

---

## 案例 B1：城市边界扩张（COLLECTION_PLAYER_CITIES）

**来源**：Siqi_Leaders_0040

```sql
INSERT INTO Types (Type, Kind) VALUES
('MODIFIER_SIQI0040_CITIES_CULTURE_BORDER_EXPANSION', 'KIND_MODIFIER');

INSERT INTO DynamicModifiers (ModifierType, EffectType, CollectionType) VALUES
('MODIFIER_SIQI0040_CITIES_CULTURE_BORDER_EXPANSION',
 'EFFECT_ADJUST_CITY_CULTURE_BORDER_EXPANSION', 'COLLECTION_PLAYER_CITIES');

INSERT INTO Modifiers(ModifierId, ModifierType) VALUES
('MODIFIER_SIQI_0040_MODIFIER_SIQI0040_CITIES_CULTURE_BORDER_EXPANSION_200',
 'MODIFIER_SIQI0040_CITIES_CULTURE_BORDER_EXPANSION');

INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0040_MODIFIER_SIQI0040_CITIES_CULTURE_BORDER_EXPANSION_200', 'Amount', 200);
```

## 案例 B3：全单位移动力（COLLECTION_ALL_UNITS）

**来源**：Siqi_Leaders_0041

```sql
-- 标准 MODIFIER_PLAYER_UNIT_ADJUST_MOVEMENT 的 CollectionType 是 COLLECTION_OWNER
-- 但需要作用于全图所有单位（包括敌方），故自定义 COLLECTION_ALL_UNITS

INSERT INTO Types (Type, Kind) VALUES
('MODIFIER_SIQI0041_ALL_UNITS_ADJUST_MOVEMENT', 'KIND_MODIFIER');

INSERT INTO DynamicModifiers (ModifierType, EffectType, CollectionType) VALUES
('MODIFIER_SIQI0041_ALL_UNITS_ADJUST_MOVEMENT',
 'EFFECT_ADJUST_UNIT_MOVEMENT', 'COLLECTION_ALL_UNITS');

INSERT INTO Modifiers(ModifierId, ModifierType, SubjectRequirementSetId) VALUES
('MODIFIER_SIQI_0041_ADJUST_MOVEMENT_N1', 'MODIFIER_SIQI0041_ALL_UNITS_ADJUST_MOVEMENT',
 'REQSET_SIQI_0041_PLOT_ADJACENT_TO_OWNER_AT_WAR');

INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0041_ADJUST_MOVEMENT_N1', 'Amount', -1);
```

## 常用 CollectionType

| CollectionType | 作用范围 |
|---------------|---------|
| `COLLECTION_OWNER` | 单个对象自身（通过 Trait 挂载时 = 玩家） |
| `COLLECTION_OWNER_CITY` | 单个城市 |
| `COLLECTION_PLAYER_CITIES` | 玩家的所有城市 |
| `COLLECTION_ALL_CITIES` | 全游戏所有城市 |
| `COLLECTION_PLAYER_UNITS` | 玩家的所有单位 |
| `COLLECTION_ALL_UNITS` | 全游戏所有单位 |
| `COLLECTION_PLAYER_GOVERNORS` | 玩家的总督 |
| `COLLECTION_PLAYER_DISTRICTS` | 玩家的区域 |
| `COLLECTION_CITY_DISTRICTS` | 某个城市的所有区域 |
| `COLLECTION_PLAYER_IMPROVEMENTS` | 玩家的改良设施 |
| `COLLECTION_ALL_PLAYERS` | 全游戏所有玩家 |
| `COLLECTION_MAJOR_PLAYERS` | 主要文明玩家 |
| `COLLECTION_PLAYER_CAPITAL_CITY` | 玩家首都 |
