## 目的

为 mod 的**领袖圆形头像**（`ICON_LEADER_*`，外交/HUD/领袖列表用）做素材整备：
合规判定 → （不合规时）定标合成与底图换色 → 规范成品 PNG。**只做素材层**，
注册走 `civ6-modding/art-pipeline.md` 的 `leader_icon` role（8 尺寸 32/45/48/50/55/64/80/256，
manifest 接线见该文件 §三/§四）。

## 底图真源

`assets/TEMPLATE_leader_avatar_base.png`（可 `--base` 覆盖）：

- 256×256 画布，暗青蓝渐变圆盘：径向拟合 **R=117.3（⌀234.6）**，圆心 (129,128)（流程规范化取画布居中）。
- 中心 RGB≈(32,55,63) → 边缘趋暗，1~2px 抗锯齿缘；盘的 alpha 即"圆形区域"，一切判定与裁切以它为准。
- **底图换色**（仅 Icon 制作支路触发）：色相 → 角色主色相（饱和像素 HSV 圆平均，权重=饱和度×覆盖度）、
  饱和度钳制 0.05~0.28、明度逐像素保留（渐变结构不变）。这是 §1.0"禁止调色"的**唯一显式豁免**，
  且只作用于底图层，主体像素永远不动。

## 三分判定（判定器 = 验收器）

| 判定 | 程序化信号 | 支路 |
|---|---|---|
| 形状不合规 | 满幅不透明矩形（复杂背景）→ **停下询问**；透明抠图/无圆形蒙版 → Icon 制作 | 圆缘贴合合成 + 占幅定标 + 底图换色 |
| 画幅不对 | 已是圆头像格式，构图/占比偏离定标带 | 仅等比缩放 + 锚定平移（禁止其它改动） |
| 合规 | 圆头像格式且占比在带内 | **合规直通**，零像素改动 |

判定器同时是验收器：检验既有头像跑同一套量测，圆外延伸按「合理延伸」豁免（见下）。

## 锚点采集（AI 视觉定位 + 机械核验）

锚点**由 AI 视觉定位提供**（脚本 `--anchors` 接 JSON），采集口径：

1. **双眼分别定位**（左右瞳/眼缝中心，两个独立点）——禁止直接报"双眼连线中点"。
2. **唇中心**；**下巴最低点**（面部轮廓最下端）。
3. **头冠点**：**脸部中心所在竖直方向上**、由视觉定位的头部圆弧轮廓顶点
   （覆盖头顶的头发主体轮廓计入；悬浮碎发丝、不相连突出物不计）。
   采集时先在源图画出该竖直线（诊断图留证），再由视觉在竖线上定位。
4. **肩线 y**：左右肩最外侧轮廓连线高度（被衣物遮挡时取可见肩轮廓并注明）。
5. **机械核验**：肤色紧致组件（侵蚀断桥 + 连通域）质心与视觉鼻点距离 >5% 画宽 → 标注低置信、人工复核；
   标号诊断图随产物交付。

锚点 JSON 契约（素材原生像素坐标）：

```json
{"L": [x,y], "R": [x,y], "lip": [x,y], "chin": y, "crown": [x,y], "shoulder": y}
```

## 定标公式

- **脸部中心** = 双眼中点与唇中心的中点；脸中心 x → 画布中心（水平锚）。
- **底边 B** = 下巴与肩线的中点（`B = 下巴 + (肩线 − 下巴)/2`），落**圆底**。
- **顶部间隙 g = (肩线 − 下巴)/4**（下巴→底边距离 H 的一半），从**头冠点**量到圆缘上沿。
- **缩放 s = 盘径 ÷ (B − 头冠 + g)**——头冠落圆顶下 g、底边落圆底（闭合解，复测偏差 ≤1px）。
- 护轨：带内（|x−脸中心x| ≤ 0.35×画宽）α≥32 可见内容顶 <2px 时整体下移。

## 圆缘贴合与出圈三规则

- **圆缘贴合**：艺术层 alpha 与底图 alpha 求交——肩胸等规则体量全部裁回圆内，
  Icon 圆形轮廓严格 = 底图圆（切口即底图自身的 AA 圆缘）。
- **出圈仅限不规则延伸**（发梢/发饰/耳朵/角/发型）：连通域整体位于上半区（+5% 画幅容差）才保留；
  深度上限 = 盘半径 ×1.18 与 **⌀画布−4px 画布圆软边界**取小（逐像素 AA 收尾，杜绝画布缘平直截断）；
  向下与左下/右下方向不保留出圈。
- ⚠ **物理边界**：头冠下移留顶隙后，高于头冠的突出物（头饰/耳朵/角）受画布上缘限制，
  超出部分沿画布缘软裁。需完整保留时由作者在「减小 g」与「缩小脸占比」间定夺，脚本不做主。

## 用法

```bash
python scripts/prepare_leader_avatar.py --material 立绘.png --anchors 锚点.json --outdir out
python scripts/prepare_leader_avatar.py --material 立绘.png --anchors 锚点.json --outdir out --canvas 256 --canvas 300
python scripts/prepare_leader_avatar.py --material 圆头像成品.png --anchors 锚点.json --outdir out --passthrough
```

- `--passthrough`：合规直通支路（只出画布导出与预览，零像素改动）。
- 批量 = 多次调用（每素材一份锚点 JSON）。

## 验证（收敛判据 = 退出码 + 复测落位）

1. 脚本退出码 0；`*_metrics.json` 中每画布：`crown_f − 圆顶 ≈ g×s`、`bound_f ≈ 圆底`（容差 ≤2px）。
2. `edge_hard = 0`（四缘 α≥200 硬接触为零——出圈物由软边界 AA 收尾）。
3. 换色底图与角色主色相一致（报告 hue），主体像素与素材逐位一致（除圆缘/出圈裁切）。
4. 人眼验收：棋盘底 `_preview_*.png` 对照原版图标观感；锚点标注图核对五官定位。
5. 不达标 → 按 §三 停下询问，不自行调参迭代。

## 交付要求

- 报告必须写明：实际使用的素材与锚点来源（视觉定位 + 核验偏差）、底边/顶隙落位、
  出圈保留/裁回量、四缘硬接触数、换色色相。
- 标注"待用户审核"后再进 DDS/.tex 与注册链（§七 滞后规则）。

## 边界

- 不做 3D 纸片人（→ 类别④）、不做 FrontEnd 立绘/背景（→ 类别⑦）、不做注册链与 DDS。
- 满幅不透明素材（复杂背景）不承接抠图 → 停下询问。
- 高耸头饰超出画布物理空间时如实报告裁切量，不自动缩小脸占比。
