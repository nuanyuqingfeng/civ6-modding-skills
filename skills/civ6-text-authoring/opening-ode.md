# 类 3 —— 开幕颂词（领袖加载介绍词）规范

> **定义**：**开幕颂词 = 每位领袖在加载界面显示的介绍词**，tag 形如
> `LOC_LOADING_INFO_LEADER_<LEADER>`（70 条，含通用兜底 `LOC_LOADING_INFO_LEADER_DEFAULT`）。
> 以第二人称对即将开局的领袖致辞，属仪式性叙事文本。
> 语料：`reference/catalog/opening_ode.tsv` ｜ 查询：`zh_corpus.sqlite` `WHERE Category='opening_ode'`
> （本类共 179 条 = 70 条领袖加载介绍词 + 109 条时代旁白 `LOC_ERA_*`，后者为同类仪式旁白，见 §5）

> ⚠️ **不要与「时代旁白」混淆**：`LOC_ERA_*_DESCRIPTION`（进入新时代时的旁白）是本类的**次级成员**；
> 用户所指「开幕颂词」的主体是**领袖加载介绍词** `LOC_LOADING_INFO_LEADER_*`。
> 检索本类时优先按 `LOC_LOADING_INFO_LEADER_` 前缀定位。

## 1. tag 结构

```
LOC_LOADING_INFO_LEADER_<LEADER>      领袖加载介绍词（<LEADER> 与 Leaders.LeaderType 同名去前缀）
LOC_LOADING_INFO_LEADER_DEFAULT       通用兜底（无专属介绍词时的回退文案）
```

- 同一领袖多文明（如忽必烈中国/蒙古）会有多条：`LOC_LOADING_INFO_LEADER_KUBLAI_KHAN_CHINA` / `..._MONGOLIA`。
- 领袖立绘/加载界面背景的**美术**注册不属本 skill → `civ6-asset-forge` 的 `reference/frontend-portrait.md`
  （其中 `LoadingInfo` 表与 `LOC_LOADING_INFO_LEADER_*` 文本一一对应）。

## 3. 文风与结构规范（从母本提炼）

1. **三段式**：`呼名（头衔/称号） → 处境与禀赋的意象 → 召唤/嘱托`。
   - 呼名：直接以领袖名领起（「成吉思汗，」「伊丽莎白一世，英国童贞女王，」「狄多女王，迦太基之母，」）。
   - 意象：把该文明的**独特单位/地貌/资源**化为意象（怯薛弓箭手、大象勇士、海洋与舰队、五湖四海）。
   - 召唤：祈使句收尾（「切莫向任何人低头…！」「率领您忠实的舰队…吧！」）。
2. **第二人称致辞**：通篇「你 / 您」（母本两者混用，均为官方允许；同一篇内保持一致即可）。
3. **两条含蓄点明玩法**：以意象暗示该文明的核心机制（如甘地→「待人友善 / 大象勇士」= 非暴力与战象），**但不写数值、不写 `[ICON_x]`**。
4. **不出现规则句**：介绍词里**不写** `+N [ICON_Y]`、条件从句（那是类1/类2 的职责）。
5. **长度**：母本约 40–140 字；长名单型（多称号）可更长。
6. **必须有 `_DEFAULT` 兜底**：为新增领袖写介绍词时，`LOC_LOADING_INFO_LEADER_DEFAULT` 保持存在（引擎回退）。

## 4. 「最大程度保留参考 + 优化措辞」作业法

为**自定义领袖**写开幕颂词时：

1. **锚定母本**：从 §2 选一个**气质/机制最接近**的官方母本（如写航海文明锚狄多、写游牧锚成吉思汗）。
2. **最大程度保留**：沿用母本的**三段式骨架、呼名方式、意象密度、祈使收尾**。
3. **替换意象**：把文明专属单位/地貌/图腾换成本文明的，保持同等具象度。
4. **优化措辞**：仅做顺句 / 去重 / 提词 / 收束（结尾召唤更利落）；**不改风格、不加口语/网络语、不增删段落**。
5. **校验**：与母本并排比对，差异应只在「意象与用词」，不在「结构与腔调」。

## 5. 附：时代旁白（同类仪式旁白，次级）

进入新时代时播报的旁白，`LOC_ERA_<ERA>_DESCRIPTION`（8 条：远古→信息，另有未来时代）：

```
LOC_ERA_ANCIENT_DESCRIPTION = 从水下第一个生命的萌芽开始…到石器时代的巨型野兽…再到人类第一次直立行走，你已经历许多。现在，开启你最伟大的探索吧：从早期文明的摇篮到浩瀚星宇。
LOC_ERA_CLASSICAL_DESCRIPTION = 从卑微的最初，你就展示出了非凡的成长力。从青铜到钢铁，用马匹和刀剑来统治吧。天空开始揭示出自己的秘密，宇宙让我们为之兴奋，星空指引我们来到异国海岸。
LOC_ERA_INDUSTRIAL_DESCRIPTION = 机器嗡嗡响个不停、烟味刺鼻、灰烬和煤烟遮挡住视线——这是时代变迁的标志。科学和文化进步的诱惑是推动你的王国不断向前发展的动力。现在，你面临的挑战是维持地球和人类、和平与战争之间微妙的平衡。
```

（其余见 `zh_corpus.sqlite` `WHERE Tag LIKE 'LOC_ERA%_DESCRIPTION'`）
同属「仪式性旁白」，套用 §3/§4 的同一作业法；区别仅在**致辞对象**：领袖介绍词对「领袖」，时代旁白对「文明/时代」。

## 6. 命名与落点

- 新领袖：新增 `LOC_LOADING_INFO_LEADER_<LEADER>`，**不要改官方 tag 值**（会污染其它环境）。
- 加载界面的 `LoadingInfo` 数据表绑定见 `civ6-asset-forge/reference/frontend-portrait.md`。
- 自定义时代旁白：新增 `LOC_ERA_<ERA>_DESCRIPTION`，不改官方 `LOC_ERA_*_DESCRIPTION`。

## 7. 校验清单

- [ ] 主体为 `LOC_LOADING_INFO_LEADER_<LEADER>`；`_DEFAULT` 兜底存在
- [ ] 第二人称、三段式、无规则数值、无 `[ICON_x]`
- [ ] 与所选母本并排比对：结构与腔调同源、仅意象与用词有别
- [ ] 多领袖文明（同一领袖多文明）逐条建 tag
- [ ] 新 tag 用新名，不覆盖官方 `LOC_LOADING_INFO_LEADER_*` / `LOC_ERA_*_DESCRIPTION`
