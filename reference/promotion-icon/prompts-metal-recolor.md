# 画幅对齐 + 四色重着色 · 图片处理模型提示词

> 用法：先用【第一步】把 `<你的源图.png>` 的主体盾徽调成官方占比，
> 再用【第二步】对调好的图分别跑四条颜色提示词，得到四个模板。
> 两次都上传同一张图、每次只执行一条提示词，效果最稳。
> 推荐模型：Gemini 2.5/3 Flash Image（多图编辑）、GPT-Image、豆包 Seedream。

---

## 官方占比（来自原版 Promotions32.dds 1:1 像素测量，32×32 格）

```
┌────────────────────────────┐ ─┐
│        顶部留白 12.5%       │  │
│   ┌────────────────────┐   │  │
│   │                    │   │  │
│左 │    盾徽主体         │右 │  │ 盾徽：宽 75% × 高 81~84%
│12.│   （水平居中，       │12.│  │ 左右留白各 12.5%
│5% │     保持原长宽比）   │5% │  │ 顶部留白 12.5%，底部留白 6%
│   └────────────────────┘   │  │
│        底部留白 6%          │  │
└────────────────────────────┘ ─┘
```

- 通用比例：盾徽宽 = 画布宽 × 75%；左右留白各 12.5%；顶部留白 = 画布高 × 12.5%；底部留白 ≈ 6%；**不拉伸变形**。
- 你的画布 2014×2081 的绝对值：左右各留 **252px**，盾徽宽 **1510px**；顶部留 **260px**，底部留 **130px**（盾高 1691px）。

## 第一步：画幅对齐（只动构图，不动内容和颜色）

### 中文

```
把这张图中的盾形徽章主体重新构图：保持盾徽的图形、浮雕细节、颜色、长宽比完全不变，
只调整它在画面中的大小和位置，使其满足：
1. 盾徽宽度调整为画布宽度的75%，左右留白各12.5%，水平居中；
2. 顶部留白为画布高度的12.5%，底部留白约6%；
3. 严禁拉伸、变形、裁切盾徽本体；严禁改变浮雕细节、棱线、切面和颜色；
4. 背景保持纯白，输出与原图相同分辨率（2014×2081）。
```

### English

```
Recompose this image: keep the shield badge's artwork, relief details, colors and aspect ratio
completely unchanged, and only adjust its size and position so that:
1. The badge width becomes 75% of the canvas width, with 12.5% white margin on each side, horizontally centered;
2. The top margin is 12.5% of the canvas height, the bottom margin about 6%;
3. Do not stretch, distort or crop the badge; do not alter any relief detail, bevel, facet or color;
4. Keep the background pure white; output at the original resolution (2014×2081).
```

## 第二步：四色重着色（对第一步的输出来回跑四条）

### 通用规则（每条提示词都包含）

```
要求：只改变金属配色，完全保留盾徽的浮雕结构、切面棱线、高光与阴影的位置和强度
（原图的凸起保持凸起、凹陷保持凹陷、明暗关系一比一映射到新颜色的明暗）。
上亮下暗的垂直渐变按下方给定三档颜色过渡；描边保持近黑色；顶部内缘高光带使用给定高光色。
背景纯白，不得新增或删除任何元素，输出与输入相同分辨率。
```

## 自检标准（生成后核对）

1. 占比：盾徽宽/画布宽 = 0.75（±0.02）；左右留白相等；顶部留白 ≈ 2 倍底部留白。
2. 四色抽样（盾徽内部上/中/下三点，避开中央图形）应接近上表色值（±15/通道）。
3. 浮雕：与输入图逐区域对比，凸起/凹陷/棱线位置完全一致，只有颜色不同。
4. 四张放一起：色相明显可分（白→黄→灰→棕），其余完全一致。
