# Yield / 简单效果 案例

> 这些 ModifierType 都是标准类型，**无需 DynamicModifiers 注册**，直接在 Modifiers 表中使用即可。

---

## MODIFIER_PLAYER_ADJUST_PLOT_YIELD — 玩家地块产出

### 变体 A：无条件全地块产出

```sql
-- TraitModifiers
INSERT INTO TraitModifiers (TraitType, ModifierId) VALUES
('TRAIT_CIVILIZATION_SIQI_C0040_1', 'MODIFIER_SIQI_0040_PLOT_YIELD_SCIENCE');

-- Modifiers
INSERT INTO Modifiers(ModifierId, ModifierType) VALUES
('MODIFIER_SIQI_0040_PLOT_YIELD_SCIENCE', 'MODIFIER_PLAYER_ADJUST_PLOT_YIELD');

-- ModifierArguments
INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0040_PLOT_YIELD_SCIENCE', 'Amount', 1),
('MODIFIER_SIQI_0040_PLOT_YIELD_SCIENCE', 'YieldType', 'YIELD_SCIENCE');
```

### 变体 B：SubjectRequirementSetId 过滤地块

```sql
-- 只有农场 + 邻接所有者 0-1 环的地块才加食物
INSERT INTO Modifiers(ModifierId, ModifierType, SubjectRequirementSetId) VALUES
('MODIFIER_SIQI_0040_PLOT_YIELD_FOOD_FARM_AND_OWNER', 'MODIFIER_PLAYER_ADJUST_PLOT_YIELD',
 'REQSET_SIQI_0040_FARM_AND_OWNER');

INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0040_PLOT_YIELD_FOOD_FARM_AND_OWNER', 'Amount', 2),
('MODIFIER_SIQI_0040_PLOT_YIELD_FOOD_FARM_AND_OWNER', 'YieldType', 'YIELD_FOOD');

-- RequirementSet: TEST_ALL（两个条件同时满足）
INSERT INTO RequirementSets (RequirementSetId, RequirementSetType) VALUES
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQUIREMENTSET_TEST_ALL');

INSERT INTO RequirementSetRequirements (RequirementSetId, RequirementId) VALUES
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM'),
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1');

INSERT INTO Requirements (RequirementId, RequirementType) VALUES
('REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM', 'REQUIREMENT_PLOT_IMPROVEMENT_TYPE_MATCHES'),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'REQUIREMENT_PLOT_ADJACENT_TO_OWNER');

INSERT INTO RequirementArguments (RequirementId, Name, Value) VALUES
('REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM', 'ImprovementType', 'IMPROVEMENT_FARM'),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'MaxDistance', 1),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'MinDistance', 0);
```

### 变体 C：OwnerRequirementSetId + SubjectRequirementSetId 双条件

```sql
-- Owner 条件: 玩家研究了 WRITING + Subject 条件: 地块是农场
INSERT INTO Modifiers(ModifierId, ModifierType, OwnerRequirementSetId, SubjectRequirementSetId) VALUES
('MODIFIER_SIQI_L0026_L1_ADJUST_PLOT_YIELD_SCIENCE_FARM_WRITING', 'MODIFIER_PLAYER_ADJUST_PLOT_YIELD',
 'SIQI0026_HAS_TECH_WRITING', 'SIQI0026_IS_IMPROVEMENT_FARM');

-- Owner RequirementSet
INSERT INTO RequirementSets (RequirementSetId, RequirementSetType) VALUES
('SIQI0026_HAS_TECH_WRITING', 'REQUIREMENTSET_TEST_ALL');

INSERT INTO Requirements (RequirementId, RequirementType) VALUES
('REQ_SIQI0026_HAS_TECH_WRITING', 'REQUIREMENT_PLAYER_HAS_TECHNOLOGY');

INSERT INTO RequirementArguments (RequirementId, Name, Value) VALUES
('REQ_SIQI0026_HAS_TECH_WRITING', 'TechnologyType', 'TECH_WRITING');
```

### 变体 D：TEST_ANY 多地形 OR 条件

```sql
-- 冻土 或 冻土(丘陵) 或 雪地 或 雪地(丘陵) — 任一满足
INSERT INTO RequirementSets (RequirementSetId, RequirementSetType) VALUES
('REQSET_SIQI_0041_TUNDRA_OR_HILLS_OR_SNOW_OR_HILLS', 'REQUIREMENTSET_TEST_ANY');

INSERT INTO RequirementSetRequirements (RequirementSetId, RequirementId) VALUES
('REQSET_SIQI_0041_TUNDRA_OR_HILLS_OR_SNOW_OR_HILLS', 'REQ_SIQI_0041_PLOT_TERRAIN_TUNDRA'),
('REQSET_SIQI_0041_TUNDRA_OR_HILLS_OR_SNOW_OR_HILLS', 'REQ_SIQI_0041_PLOT_TERRAIN_SNOW');

INSERT INTO Requirements (RequirementId, RequirementType) VALUES
('REQ_SIQI_0041_PLOT_TERRAIN_TUNDRA', 'REQUIREMENT_PLOT_TERRAIN_TYPE_MATCHES'),
('REQ_SIQI_0041_PLOT_TERRAIN_SNOW', 'REQUIREMENT_PLOT_TERRAIN_TYPE_MATCHES');

INSERT INTO RequirementArguments (RequirementId, Name, Value) VALUES
('REQ_SIQI_0041_PLOT_TERRAIN_TUNDRA', 'TerrainType', 'TERRAIN_TUNDRA'),
('REQ_SIQI_0041_PLOT_TERRAIN_SNOW', 'TerrainType', 'TERRAIN_SNOW');
```

## MODIFIER_SINGLE_CITY_ADJUST_CITY_YIELD_MODIFIER — 城市产出%修正

```sql
-- 城市 +25% 生产力（条件：领袖匹配）
INSERT INTO ImprovementModifiers (ImprovementType, ModifierId) VALUES
('IMPROVEMENT_MINE', 'MODIFIER_SIQI_0042_CITY_YIELD_MODIFIER_PRODUCTION_LEADER_L0042');

INSERT INTO Modifiers(ModifierId, ModifierType, SubjectRequirementSetId) VALUES
('MODIFIER_SIQI_0042_CITY_YIELD_MODIFIER_PRODUCTION_LEADER_L0042',
 'MODIFIER_SINGLE_CITY_ADJUST_CITY_YIELD_MODIFIER', 'REQSET_SIQI_0042_LEADER_L0042');

INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0042_CITY_YIELD_MODIFIER_PRODUCTION_LEADER_L0042', 'Amount', 25),
('MODIFIER_SIQI_0042_CITY_YIELD_MODIFIER_PRODUCTION_LEADER_L0042', 'YieldType', 'YIELD_PRODUCTION');
```

> 注意：这是**百分比**修正（不是绝对值），Amount=25 → +25%。

## MODIFIER_PLAYER_GRANT_SPECIFIC_TECHNOLOGY — 赠送科技

```sql
INSERT INTO Modifiers(ModifierId, ModifierType) VALUES
('MODIFIER_SIQI_0042_GRANT_TECH_MINING', 'MODIFIER_PLAYER_GRANT_SPECIFIC_TECHNOLOGY');

INSERT INTO ModifierArguments (ModifierId, Name, Value) VALUES
('MODIFIER_SIQI_0042_GRANT_TECH_MINING', 'TechType', 'TECH_MINING');
```

> 只有 `TechType` 一个参数。值来自 `Technologies.TechnologyType` 如 `TECH_MINING`、`TECH_WRITING`、`TECH_ASTROLOGY`。

## 其他常用简单 ModifierType 参数速查

| ModifierType | 参数 | 用途 |
|-------------|------|------|
| `MODIFIER_UNIT_ADJUST_COMBAT_STRENGTH` | `Amount` | 单单位战斗力 |
| `MODIFIER_PLAYER_UNITS_ADJUST_COMBAT_STRENGTH` | `Amount` | 全单位战斗力 |
| `MODIFIER_PLAYER_UNIT_ADJUST_DAMAGE` | `Amount` (-100=治疗) | 单位治疗/伤害 |
| `MODIFIER_PLAYER_UNIT_ADJUST_HEAL_FROM_COMBAT` | `Amount` | 击杀回血% |
| `MODIFIER_PLAYER_UNIT_ADJUST_MOVEMENT` | `Amount` | 移动力 |
| `MODIFIER_PLAYER_UNIT_ADJUST_SIGHT` | `Amount` | 视野 |
| `MODIFIER_PLAYER_UNIT_ADJUST_HIDDEN_VISIBILITY` | `Hidden` (0/1) | 隐匿 |
| `MODIFIER_PLAYER_UNIT_ADJUST_IGNORE_TERRAIN_COST` | `Ignore` (0/1), `Type` ('ALL') | 无地形惩罚 |
| `MODIFIER_PLAYER_UNIT_ADJUST_IGNORE_ZOC` | `Ignore` (0/1) | 无视 ZOC |
| `MODIFIER_PLAYER_UNIT_ADJUST_SEE_THROUGH_FEATURES` | `CanSee` (0/1) | 穿透地貌 |
| `MODIFIER_PLAYER_UNIT_ADJUST_SEE_THROUGH_TERRAIN` | `CanSee` (0/1) | 穿透地形 |
| `MODIFIER_SINGLE_CITY_CULTURE_BORDER_EXPANSION` | `Amount` | 边界扩张% |
| `MODIFIER_SINGLE_CITY_ADJUST_EXTRA_GREAT_WORK_SLOTS` | `Amount`, `BuildingType`, `GreatWorkSlotType` | 额外巨作槽 |
| `MODIFIER_PLAYER_CITIES_ADJUST_CITY_YIELD_CHANGE` | `Amount`, `YieldType` | 城市产出绝对值 |
| `MODIFIER_PLAYER_ADJUST_TRADE_ROUTE_YIELD_MODIFIER` | `Amount` | 商路产出% |
| `MODIFIER_SINGLE_CITY_ADJUST_TRADE_ROUTE_YIELD_FOR_INTERNATIONAL` | `Amount`, `YieldType` | 国际商路产出 |
| `MODIFIER_PLAYER_UNITS_ADJUST_ATTACK_RANGE` | `Amount` | 攻击射程 |
| `MODIFIER_PLAYER_ADJUST_TOURISM` | `Amount` | 旅游业绩% |
| `MODIFIER_PLAYER_CITIES_ADJUST_BUILDING_YIELD_CHANGE` | `BuildingType`, `YieldType`, `Amount` | 建筑产出 |
| `MODIFIER_PLAYER_UNITS_ADJUST_IGNORE_RIVERS` | `Ignore` (0/1) | 无视河流 |
| `MODIFIER_SINGLE_UNIT_ADJUST_COMBAT_FOR_UNUSED_MOVEMENT` | `Amount` | 按剩余移动力加战力 |
