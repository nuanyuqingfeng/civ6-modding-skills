# 复杂 RequirementSet 案例

> `REQUIREMENTSET_TEST_ALL` = AND（全部满足），`REQUIREMENTSET_TEST_ANY` = OR（任一满足）。

---

## 案例 D1：TEST_ALL 双条件 — 改良类型 AND 相邻所有者

**来源**：Siqi_Leaders_0040

```sql
INSERT INTO RequirementSets (RequirementSetId, RequirementSetType) VALUES
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQUIREMENTSET_TEST_ALL');

INSERT INTO RequirementSetRequirements (RequirementSetId, RequirementId) VALUES
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM'),
('REQSET_SIQI_0040_FARM_AND_OWNER', 'REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1');

INSERT INTO Requirements (RequirementId, RequirementType) VALUES
('REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM', 'REQUIREMENT_PLOT_IMPROVEMENT_TYPE_MATCHES'),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'REQUIREMENT_PLOT_ADJACENT_TO_OWNER');

INSERT INTO RequirementArguments (RequirementId, Name, Value) VALUES
('REQ_SIQI_0040_PLOT_IMPROVEMENT_TYPE_MATCHES_FARM', 'ImprovementType', 'IMPROVEMENT_FARM'),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'MaxDistance', 1),
('REQ_SIQI_0040_PLOT_ADJACENT_TO_OWNER_1', 'MinDistance', 0);
```

## 案例 D4：TEST_ALL + 为宗主国 AND 领袖匹配（跨玩家过滤）

**来源**：Siqi_Leaders_0045

```sql
INSERT INTO RequirementSets (RequirementSetId, RequirementSetType) VALUES
('REQSET_SIQI_0045_SUZERAIN_AND_L0045', 'REQUIREMENTSET_TEST_ALL');

INSERT INTO RequirementSetRequirements (RequirementSetId, RequirementId) VALUES
('REQSET_SIQI_0045_SUZERAIN_AND_L0045', 'REQ_SIQI_0045_IS_SUZERAIN'),
('REQSET_SIQI_0045_SUZERAIN_AND_L0045', 'REQ_SIQI_0045_LEADER_L0045');

INSERT INTO Requirements (RequirementId, RequirementType, Inverse) VALUES
('REQ_SIQI_0045_IS_SUZERAIN', 'REQUIREMENT_PLAYER_IS_SUZERAIN', 0),
('REQ_SIQI_0045_LEADER_L0045', 'REQUIREMENT_PLAYER_LEADER_TYPE_MATCHES', 0);

INSERT INTO RequirementArguments (RequirementId, Name, Value) VALUES
('REQ_SIQI_0045_LEADER_L0045', 'LeaderType', 'LEADER_SIQI_L0045_1');
```

## 事件类 Requirement（需要 Triggered=1）

```sql
-- 回合开始触发 — 必须写 Triggered=1
INSERT INTO Requirements (RequirementId, RequirementType, Triggered) VALUES
('REQ_SIQI_0040_PLAYER_TURN_STARTED', 'REQUIREMENT_PLAYER_TURN_STARTED', 1);

INSERT INTO Modifiers (ModifierId, ModifierType, OwnerRequirementSetId) VALUES
('MODIFIER_SIQI_0040_UNIT_DAMAGE_HEAL_100', 'MODIFIER_PLAYER_UNIT_ADJUST_DAMAGE',
 'REQSET_SIQI_0040_PLAYER_TURN_STARTED');
```

> 事件类 Requirement 通过 `OwnerRequirementSetId` 引用（而不是 SubjectRequirementSetId）。

## 常用 RequirementType

| RequirementType | 参数 |
|----------------|------|
| `REQUIREMENT_PLOT_IMPROVEMENT_TYPE_MATCHES` | `ImprovementType` |
| `REQUIREMENT_PLOT_TERRAIN_TYPE_MATCHES` | `TerrainType` |
| `REQUIREMENT_PLOT_FEATURE_TYPE_MATCHES` | `FeatureType` |
| `REQUIREMENT_PLOT_RESOURCE_TYPE_MATCHES` | `ResourceType` |
| `REQUIREMENT_PLOT_RESOURCE_CLASS_TYPE_MATCHES` | `ResourceClassType` |
| `REQUIREMENT_PLOT_ADJACENT_TO_OWNER` | `MinDistance`, `MaxDistance` |
| `REQUIREMENT_PLOT_ADJACENT_TO_OWNER_AT_WAR` | `MinDistance`, `MaxDistance` |
| `REQUIREMENT_PLOT_HAS_ANY_IMPROVEMENT` | 无参数 |
| `REQUIREMENT_PLOT_IS_APPEAL_BETWEEN` | `MinimumAppeal`, `MaximumAppeal` |
| `REQUIREMENT_PLOT_ADJACENT_FEATURE_TYPE_MATCHES` | `FeatureType` |
| `REQUIREMENT_PLOT_ADJACENT_DISTRICT_TYPE_MATCHES` | `DistrictType` |
| `REQUIREMENT_PLAYER_HAS_TECHNOLOGY` | `TechnologyType` |
| `REQUIREMENT_PLAYER_HAS_CIVIC` | `CivicType` |
| `REQUIREMENT_PLAYER_LEADER_TYPE_MATCHES` | `LeaderType` |
| `REQUIREMENT_PLAYER_HAS_DISTRICT` | `DistrictType` |
| `REQUIREMENT_CITY_HAS_X_POPULATION` | `Amount` |
| `REQUIREMENT_DISTRICT_TYPE_MATCHES` | `DistrictType` |
| `REQUIREMENT_PLAYER_TURN_STARTED` | 无参数，需 `Triggered=1` |
| `REQUIREMENT_PLAYER_IS_SUZERAIN` | 无参数 |
| `REQUIREMENT_PLAYER_HAS_DARK_AGE` | 无参数 |
| `REQUIREMENT_PLAYER_HAS_GOLDEN_AGE` | 无参数 |
